# Excelize v2.11.1

* 출시 예정일: 2026 년 11 월 2 일

## 릴리스 노트

이 릴리스에서 가장 주목할 만한 변경 사항은 다음과 같습니다:

### 하위 호환성 변경 사항

* 요구 사항 업데이트: 종속성 패키지 `golang.org/x/crypto` 업그레이드로 인해 Go 언어 버전 1.26.0 이상이 필요합니다

### 보안

* 음수 공유 문자열 인덱스로 셀 값 가져오기 시 패닉 수정 (CVE-2026-104819), 관련 보안 권고사항 [GHSA-48hm-4h8j-58fg](https://github.com/xuri/excelize/security/advisories/GHSA-48hm-4h8j-58fg)
* 잘못된 피벗 테이블 필드 인덱스에서 `GetPivotTables` 함수가 패닉을 일으키는 문제 수정 (CVE-2026-107211), 관련 보안 권고사항 [GHSA-mx22-3794-2vpv](https://github.com/xuri/excelize/security/advisories/GHSA-mx22-3794-2vpv)
* 행 반복자에서 행 번호가 제한 없이 허용되는 문제 수정 (CVE-2026-107212), 관련 보안 권고사항 [GHSA-jw42-f3rr-4cc3](https://github.com/xuri/excelize/security/advisories/GHSA-jw42-f3rr-4cc3)
* 그리기 부분이 없는 워크시트에서 슬라이서를 가져올 때 `GetSlicers` 함수가 패닉을 일으키는 문제 수정 (CVE-2026-107213), 관련 보안 권고사항 [GHSA-r7x5-4969-99p7](https://github.com/xuri/excelize/security/advisories/GHSA-r7x5-4969-99p7)
* 형식이 잘못된 통합 문서 복호화 시 패닉 수정 (CVE-2026-107214), 관련 보안 권고사항 [GHSA-2j4c-ffch-9f23](https://github.com/xuri/excelize/security/advisories/GHSA-2j4c-ffch-9f23)
* 통합 문서 복호화 시 `EncryptionInfo` 및 `EncryptedPackage` 스트림 크기가 제한 없이 할당되는 문제 수정 (CVE-2026-107215), 관련 보안 권고사항 [GHSA-x2q3-8cjh-766f](https://github.com/xuri/excelize/security/advisories/GHSA-x2q3-8cjh-766f)
* 순환 ANCHORARRAY 수식 참조로 인해 `CalcCellValue` 함수에서 스택 오버플로가 발생하는 문제 수정 (CVE-2026-107216), 관련 보안 권고사항 [GHSA-wp2g-vpjj-g53r](https://github.com/xuri/excelize/security/advisories/GHSA-wp2g-vpjj-g53r)
* `ColumnNameToNumber` 및 `JoinCellName` 함수가 잘못된 열 이름을 허용하여 정수 오버플로가 발생하는 문제 수정 (CVE-2026-107217), 관련 보안 권고사항 [GHSA-c85p-xxjj-2r75](https://github.com/xuri/excelize/security/advisories/GHSA-c85p-xxjj-2r75)
* LEFT, LEFTB, RIGHT 및 RIGHTB 수식 함수에서 유니코드 처리 및 개수 오버플로 수정 (CVE-2026-107218), 관련 보안 권고사항 [GHSA-8jjq-8j9w-m2v6](https://github.com/xuri/excelize/security/advisories/GHSA-8jjq-8j9w-m2v6)
* Agile 복호화 키 유도 시 스핀 횟수가 제한 없이 허용되는 문제 수정 (CVE-2026-107219), 관련 보안 권고사항 [GHSA-jrfj-fhj2-jjvm](https://github.com/xuri/excelize/security/advisories/GHSA-jrfj-fhj2-jjvm)
* 빈 병합 셀 참조가 있는 워크시트에서 패닉이 발생하는 문제 수정 (CVE-2026-107220), 관련 보안 권고사항 [GHSA-g27h-8qhm-6pff](https://github.com/xuri/excelize/security/advisories/GHSA-g27h-8qhm-6pff)
* 셀이 열 오름차순이 아닌 행에서 패닉이 발생하는 문제 수정 (CVE-2026-107221), 관련 보안 권고사항 [GHSA-8mcq-6wmr-jrjv](https://github.com/xuri/excelize/security/advisories/GHSA-8mcq-6wmr-jrjv)
* 잘못된 조건부 서식 규칙에서 `GetConditionalFormats` 함수가 패닉을 일으키는 문제 수정 (CVE-2026-107222), 관련 보안 권고사항 [GHSA-rxcj-4pj5-74gr](https://github.com/xuri/excelize/security/advisories/GHSA-rxcj-4pj5-74gr)
* 최소 및 최대 열 번호 오버플로 수정 (CVE-2026-107223), 관련 보안 권고사항 [GHSA-fq3v-74gv-27gm](https://github.com/xuri/excelize/security/advisories/GHSA-fq3v-74gv-27gm)
* 부호 있는 int64 에 맞지 않는 Zip64 압축 해제 크기를 거부하여 패닉 수정 (CVE-2026-107224), 관련 보안 권고사항 [GHSA-fw94-4wwp-w8pw](https://github.com/xuri/excelize/security/advisories/GHSA-fw94-4wwp-w8pw)
* 음수 스타일 인덱스로 스타일을 가져올 때 패닉 수정 (CVE-2026-107225), 관련 보안 권고사항 [GHSA-c85p-xxjj-2r75](https://github.com/xuri/excelize/security/advisories/GHSA-5h23-36rv-pm65)

### 새로운 기능

* 2개의 새로운 상수 추가: `MaxCFBStreamSizeV3` 및 `MaxCFBStreamSizeV4`
* `CalcCellValue` 함수에서 AND 수식 함수의 행렬 인수 지원
* `SetConditionalFormat` 함수에서 스타일 인덱스 유효성 검사, 관련 이슈 [#2400](https://github.com/xuri/excelize/issues/2400)

### 호환성 개선

* `SetCellValue` 함수로 저장되는 값의 숫자 정밀도를 Microsoft Excel&trade; 과 일치하도록 조정, 관련 이슈 [#1757](https://github.com/xuri/excelize/issues/1757)

### 버그 수정

* 일부 경우 `GetPictures` 함수가 편집 위치를 반환하지 않는 문제 수정, 이슈 [#2217](https://github.com/xuri/excelize/issues/2217)
* 괄호 또는 연산자 내에 오류 값이 있을 때 `CalcCellValue` 함수가 잘못된 계산 결과를 반환하는 문제 수정, 이슈 [#1164](https://github.com/xuri/excelize/issues/1164) 및 [#2344](https://github.com/xuri/excelize/issues/2344)
* 일부 경우 `CalcCellValue` 함수가 예상된 오류를 반환하지 않는 문제 수정, 이슈 [#2349](https://github.com/xuri/excelize/issues/2349) 및 [#2432](https://github.com/xuri/excelize/issues/2432)
* `CalcCellValue` 함수가 14개의 수식 함수에서 잘못된 결과를 반환하는 문제 수정: COUNT, COUNTA, HLOOKUP, IF, INDIRECT, ISNUMBER, MDETERM, MINVERSE, OR, SUM, TRIM, VALUE, VLOOKUP 및 XLOOKUP, 이슈 [#2411](https://github.com/xuri/excelize/issues/2411), [#2412](https://github.com/xuri/excelize/issues/2412), [#2413](https://github.com/xuri/excelize/issues/2413), [#2414](https://github.com/xuri/excelize/issues/2414), [#2415](https://github.com/xuri/excelize/issues/2415), [#2416](https://github.com/xuri/excelize/issues/2416), [#2417](https://github.com/xuri/excelize/issues/2417), [#2430](https://github.com/xuri/excelize/issues/2430), [#2436](https://github.com/xuri/excelize/issues/2436), [#2439](https://github.com/xuri/excelize/issues/2439) 및 [#2445](https://github.com/xuri/excelize/issues/2445)
* 수식에서 닫는 괄호가 맞지 않을 때 `CalcCellValue` 함수에서 패닉이 발생하는 문제 수정, 이슈 [#2409](https://github.com/xuri/excelize/issues/2409)
* 잘못된 인수로 PERCENTILE.EXC 수식 함수를 계산할 때 `CalcCellValue` 함수에서 패닉이 발생하는 문제 수정, 이슈 [#2426](https://github.com/xuri/excelize/issues/2426)
* 일부 경우 `AddChart` 및 `AddChartSheet` 함수가 통합 문서를 손상시키는 잘못된 차트를 생성하는 문제 수정, 이슈 [#2355](https://github.com/xuri/excelize/issues/2355) 및 [#2356](https://github.com/xuri/excelize/issues/2356)
* 스트림 작성기가 기간 셀 값에 숫자 서식을 적용하지 않는 문제 수정, 이슈 [#2371](https://github.com/xuri/excelize/issues/2371)
* `time.Duration`으로 셀 값을 설정할 때 정밀도가 손실되는 문제 수정, 이슈 [#2372](https://github.com/xuri/excelize/issues/2372)
* `AddSlicer` 함수가 서로 다른 필드에 대해 피벗 테이블 슬라이서 캐시를 재사용하는 문제 수정, 이슈 [#2383](https://github.com/xuri/excelize/issues/2383)
* 패턴이 없는 채우기에 대해 `GetStyle` 함수가 잘못된 스타일을 반환하는 문제 수정, 이슈 [#2384](https://github.com/xuri/excelize/issues/2384)
* 통합 문서가 절대 경로를 사용할 때 `GetFormControls` 및 `GetTables` 함수가 양식 컨트롤과 표를 가져오지 못하는 문제 수정, 이슈 [#2386](https://github.com/xuri/excelize/issues/2386)
* 일부 경우 `GetPanes` 함수가 분할 창을 가져오지 못하는 문제 수정, 이슈 [#2387](https://github.com/xuri/excelize/issues/2387)
* `SetCalcProps` 함수가 계산 속성을 false로 설정하지 못하는 문제 수정, 관련 이슈 [#2404](https://github.com/xuri/excelize/issues/2404)

### 기타

* Go Modules 는 모듈 업데이트에 의존합니다
* 단위 테스트 및 godoc 업데이트
* 다국어를 지원하는 [문서 웹사이트](https://xuri.me/excelize): 아랍어, 독일어, 영어, 스페인어, 프랑스어, 이탈리아어, 일본어, 한국어, 포르투갈어, 러시아어, 중국어 간체 및 중국어 번체, 업데이트됨
* [excelize-wasm](https://github.com/xuri/excelize-wasm) WebAssembly / JavaScript 지원을 위한 NPM 패키지 릴리스 업데이트
* [excelize](https://github.com/xuri/excelize-py) Python 을 위한 PyPI 패키지 릴리스 업데이트
* [ExcelizeCs](https://github.com/xuri/excelize-cs) C# 을 위한 NuGet .Net 패키지 릴리스 업데이트
