# Excelize v2.11.1

{{ book.info }}

* 預計釋出日期: 2026年11月2日

## 版本說明

此版本中最顯著的變化包括：

### 相容性提示

* 升級 Go 語言版本要求至 1.26.0 或更高版本，以升級依賴包 `golang.org/x/crypto`

### 安全更新

* 修復當共享字串索引為負數時取得儲存格值引發程式 panic 的問題 (CVE-2026-104819)，相關安全公告 [GHSA-48hm-4h8j-58fg](https://github.com/xuri/excelize/security/advisories/GHSA-48hm-4h8j-58fg)
* 修復 `GetPivotTables` 函式在樞紐分析表欄位索引無效時引發程式 panic 的問題 (CVE-2026-107211)，相關安全公告 [GHSA-mx22-3794-2vpv](https://github.com/xuri/excelize/security/advisories/GHSA-mx22-3794-2vpv)
* 修復列迭代器對列號無限制的問題 (CVE-2026-107212)，相關安全公告 [GHSA-jw42-f3rr-4cc3](https://github.com/xuri/excelize/security/advisories/GHSA-jw42-f3rr-4cc3)
* 修復 `GetSlicers` 函式從不含繪圖部件的工作表中獲取交叉分析篩選器時引發程式 panic 的問題 (CVE-2026-107213)，相關安全公告 [GHSA-r7x5-4969-99p7](https://github.com/xuri/excelize/security/advisories/GHSA-r7x5-4969-99p7)
* 修復解密格式錯誤的活頁簿時引發程式 panic 的問題 (CVE-2026-107214)，相關安全公告 [GHSA-2j4c-ffch-9f23](https://github.com/xuri/excelize/security/advisories/GHSA-2j4c-ffch-9f23)
* 修復解密活頁簿時無限制分配 `EncryptionInfo` 和 `EncryptedPackage` 串流大小的問題 (CVE-2026-107215)，相關安全公告 [GHSA-x2q3-8cjh-766f](https://github.com/xuri/excelize/security/advisories/GHSA-x2q3-8cjh-766f)
* 修復 `CalcCellValue` 函式因 ANCHORARRAY 公式循環引用導致堆疊溢位的問題 (CVE-2026-107216)，相關安全公告 [GHSA-wp2g-vpjj-g53r](https://github.com/xuri/excelize/security/advisories/GHSA-wp2g-vpjj-g53r)
* 修復 `ColumnNameToNumber` 和 `JoinCellName` 函式接受無效欄名而導致整數溢位的問題 (CVE-2026-107217)，相關安全公告 [GHSA-c85p-xxjj-2r75](https://github.com/xuri/excelize/security/advisories/GHSA-c85p-xxjj-2r75)
* 修復 LEFT、LEFTB、RIGHT 和 RIGHTB 公式函式中 Unicode 處理和字元數溢位的問題 (CVE-2026-107218)，相關安全公告 [GHSA-8jjq-8j9w-m2v6](https://github.com/xuri/excelize/security/advisories/GHSA-8jjq-8j9w-m2v6)
* 修复解密带有敏捷加密算法的活页簿时，金鑰自旋次数无限制的问题 (CVE-2026-107219)，相關安全公告 [GHSA-jrfj-fhj2-jjvm](https://github.com/xuri/excelize/security/advisories/GHSA-jrfj-fhj2-jjvm)
* 修復工作表中存在空合併存儲格引用時引發程式 panic 的問題 (CVE-2026-107220)，相關安全公告 [GHSA-g27h-8qhm-6pff](https://github.com/xuri/excelize/security/advisories/GHSA-g27h-8qhm-6pff)
* 修復列內存儲格未按欄升序排列時引發程式 panic 的問題 (CVE-2026-107221)，相關安全公告 [GHSA-8mcq-6wmr-jrjv](https://github.com/xuri/excelize/security/advisories/GHSA-8mcq-6wmr-jrjv)
* 修復 `GetConditionalFormats` 函式在條件格式規則格式錯誤時引發程式 panic 的問題 (CVE-2026-107222)，相關安全公告 [GHSA-rxcj-4pj5-74gr](https://github.com/xuri/excelize/security/advisories/GHSA-rxcj-4pj5-74gr)
* 修復最小和最大欄名稱溢位的問題 (CVE-2026-107223)，相關安全公告 [GHSA-fq3v-74gv-27gm](https://github.com/xuri/excelize/security/advisories/GHSA-fq3v-74gv-27gm)
* 修復因解壓縮大小溢位導致開啟活頁簿引發程式 panic 的問題 (CVE-2026-107224)，相關安全公告 [GHSA-fw94-4wwp-w8pw](https://github.com/xuri/excelize/security/advisories/GHSA-fw94-4wwp-w8pw)
* 修復使用負數樣式索引獲取樣式時引發程式 panic 的問題 (CVE-2026-107225)，相關安全公告 [GHSA-c85p-xxjj-2r75](https://github.com/xuri/excelize/security/advisories/GHSA-5h23-36rv-pm65)

### 新增功能

* 新增 2 個常數：`MaxCFBStreamSizeV3` 和 `MaxCFBStreamSizeV4`
* `CalcCellValue` 函數支援計算帶有陣列公式參數的 AND 公式函數
* `SetConditionalFormat` 函式支援驗證樣式索引，相關 issue [#2400](https://github.com/xuri/excelize/issues/2400)

### 相容性提升

* 函式 `SetCellValue` 儲存數值的精度與 Microsoft Excel&trade; 一致，相關 issue [#1757](https://github.com/xuri/excelize/issues/1757)

### 問題修復

* 修復 `GetPictures` 函式在某些情況下未傳回圖片位置屬性的問題，解決 issue [#2217](https://github.com/xuri/excelize/issues/2217)
* 修復 `CalcCellValue` 函式計算括號或運算符內包含錯誤值的公式時傳回錯誤計算結果的問題，解決 issue [#1164](https://github.com/xuri/excelize/issues/1164) 和 [#2344](https://github.com/xuri/excelize/issues/2344)
* 修復 `CalcCellValue` 函式在某些情況下未傳回預期錯誤的問題，解決 issue [#2349](https://github.com/xuri/excelize/issues/2349) 和 [#2432](https://github.com/xuri/excelize/issues/2432)
* 修復 `CalcCellValue` 函式在計算 14 個公式函式時傳回錯誤結果的問題：COUNT、COUNTA、HLOOKUP、IF、INDIRECT、ISNUMBER、MDETERM、MINVERSE、OR、SUM、TRIM、VALUE、VLOOKUP 和 XLOOKUP，解決 issue [#2411](https://github.com/xuri/excelize/issues/2411)、[#2412](https://github.com/xuri/excelize/issues/2412)、[#2413](https://github.com/xuri/excelize/issues/2413)、[#2414](https://github.com/xuri/excelize/issues/2414)、[#2415](https://github.com/xuri/excelize/issues/2415)、[#2416](https://github.com/xuri/excelize/issues/2416)、[#2417](https://github.com/xuri/excelize/issues/2417)、[#2430](https://github.com/xuri/excelize/issues/2430)、[#2436](https://github.com/xuri/excelize/issues/2436)、[#2439](https://github.com/xuri/excelize/issues/2439) 和 [#2445](https://github.com/xuri/excelize/issues/2445)
* 修復 `CalcCellValue` 函式在公式中右括號不匹配時引發程式 panic 的問題，解決 issue [#2409](https://github.com/xuri/excelize/issues/2409)
* 修復 `CalcCellValue` 函式計算含有無效參數的 PERCENTILE.EXC 公式函式時引發程式 panic 的問題，解決 issue [#2426](https://github.com/xuri/excelize/issues/2426)
* 修復 `AddChart` 和 `AddChartSheet` 函式在某些情況下生成無效圖表導致活頁簿損壞的問題，解決 issue [#2355](https://github.com/xuri/excelize/issues/2355) 和 [#2356](https://github.com/xuri/excelize/issues/2356)
* 修復串流寫入器未對時間間隔類型的存儲格值套用數字格式的問題，解決 issue [#2371](https://github.com/xuri/excelize/issues/2371)
* 修復使用 `time.Duration` 資料類型的值設定存儲格值時精度遺失的問題，解決 issue [#2372](https://github.com/xuri/excelize/issues/2372)
* 修復 `AddSlicer` 函式為資料透視表的不同欄位重複使用相同切片器快取的問題，解決 issue [#2383](https://github.com/xuri/excelize/issues/2383)
* 修復 `GetStyle` 函式對無圖案填滿傳回無效樣式的問題，解決 issue [#2384](https://github.com/xuri/excelize/issues/2384)
* 修復 `GetFormControls` 和 `GetTables` 函式無法取得工作簿內部帶有絕對路徑部件的表單控制項和表格的問題，解決 issue [#2386](https://github.com/xuri/excelize/issues/2386)
* 修復 `GetPanes` 函式在某些情況下無法獲取分割窗格的問題，解決 issue [#2387](https://github.com/xuri/excelize/issues/2387)
* 修復 `SetCalcProps` 函式無法將計算屬性設定為 false 的問題，相關 issue [#2404](https://github.com/xuri/excelize/issues/2404)

### 其他

* Go Modules 依賴模塊更新
* 單元測試與文檔更新
* 包含阿拉伯語、德語、英語、西班牙語、法語、意大利語、日語、韓語、葡萄牙語、俄語、簡體中文和繁體中文的[多國語言文檔網站](https://xuri.me/excelize)更新

* 支援 C# 的 [ExcelizeCs](https://github.com/xuri/excelize-cs) NuGet .Net 包發佈版本更新
